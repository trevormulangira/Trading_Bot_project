# EUR/USD Trading Bot

## Overview

This project is an ongoing machine learning project focused on developing a trading bot for the EUR/USD currency pair.

The goal is to build a systematic trading pipeline that processes market data, engineers useful features, trains predictive models, and eventually evaluates trading strategies.

## Project Structure

* `main.py` — Main project entry point
* `data_inspection.py` — Data inspection
* `create_target.py` — Target creation
* `feature_engineering.py` — Feature engineering
* `check_useful_features.py` — Feature analysis
* `check_safe_removal_of_duplicates.py` — Duplicate-removal checks
* `remove_duplicates.py` — Duplicate removal
* `inspect_model_mistakes.py` — Model error inspection

## Current Focus

Building a reliable machine learning workflow before developing and testing a complete trading strategy.
